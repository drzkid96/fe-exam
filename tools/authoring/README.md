# Authoring scripts

The site content under `site/content/` is generated by these scripts. Edit the scripts, then run `sh tools/authoring/build.sh`, then `sh tools/check.sh`.

| Script | Writes |
|---|---|
| `author_a.py`, `author_b.py`, `author_d1.py`, `author_d2.py` | The base question of every question type, with its independent calculation |
| `author_v.py` | The version generator and the figure library (beams, trusses, sections, soil profiles, curves and so on) |
| `author_v1.py` to `author_v4.py` | Numeric version families: stem, concept, solution and distractor formulas per type |
| `author_v5.py` | Second written versions for rule-and-judgement types |
| `author_hb.py` | Handbook chapter, pages and search words per question type |
| `author_c.py` | Topic overviews and the handbook map |
| `guide_dsl.py`, `author_g1.py` to `author_g3.py` | The base lesson for each subtopic |
| `author_fig.py` | Lesson figures |
| `author_depth.py`, `author_ex.py` | Key ideas, worked examples and handbook lookups in lessons |
| `author_deep.py` | In-depth sections, solving methods, outside links and review-session tips |

The manifest version in `site/content/manifest.json` is bumped by hand. Everything here is original work; do not paste text or figures from the handbook, prep books or exams into these files.
